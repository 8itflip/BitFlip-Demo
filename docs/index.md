# BitFlip Demo

BitFlip Demo is a Node.js application used for testing CI/CD pipelines and demonstrating the ClickOps Internal Developer Platform.

## Overview

- **Runtime**: Node.js with Express
- **Owner**: ClickOps Team
- **System**: ClickOps Platform
- **Lifecycle**: Experimental

## Quick Start

```bash
npm install
node app.js
```

## Features

- REST API endpoints for demo purposes
- CI/CD pipeline integration
- Kubernetes deployment via ArgoCD
- Monitoring with SonarQube integration
